# Week 8: E-Commerce Order Analytics System using Python, Pandas and MySQL

## Objective

The objective of this assignment was to design and develop an end-to-end E-Commerce Order Analytics System using Python, Pandas, and MySQL. The assignment focused on generating realistic datasets, introducing data inconsistencies, performing data cleaning, loading cleaned data into a relational database, writing SQL queries for business analysis, and generating business reports with visualizations.

---

## Tools Used

- Python
- Pandas
- Faker
- MySQL
- MySQL Workbench
- Matplotlib

---

## Dataset

A realistic e-commerce dataset was generated using the Faker library. The dataset consists of four related tables:

- Customers
- Products
- Orders
- Order Items

Intentional inconsistencies such as duplicate records, null values, invalid customer IDs, invalid product IDs, incorrect email addresses, invalid dates, and invalid quantities were introduced to simulate real-world data quality issues.

---

## Tasks Performed

During this assignment, the following tasks were completed:

- Generated realistic customer, product, order, and order item datasets using Python.
- Introduced intentional inconsistencies into the datasets.
- Exported the generated datasets as CSV files.
- Cleaned the datasets using Pandas.
- Removed duplicate records.
- Handled missing values.
- Corrected invalid email addresses.
- Removed invalid customer and product references.
- Removed invalid order records.
- Generated cleaned datasets and an issue report.
- Created relational tables in MySQL.
- Loaded cleaned datasets into MySQL.
- Performed SQL analysis using basic, intermediate, and advanced queries.
- Calculated business metrics such as revenue, customer spending, monthly revenue, product performance, and regional sales.
- Generated business reports using Python.
- Created data visualizations for business insights.
- Exported reports in CSV format and charts in PNG format.

---

## Output

The project successfully generates:

- Raw datasets
- Cleaned datasets
- Issue report
- SQL analysis results
- Revenue reports
- Business charts
- CSV report files
- PNG visualizations

---

## Learning Outcomes

After completing this assignment, I understood how to generate realistic datasets using Python and Faker, clean and preprocess data using Pandas, load data into a MySQL database, and perform business analysis using SQL. I also learned how to generate business reports and visualizations using Python and Matplotlib.
