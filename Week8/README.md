# Week 8: E-Commerce Order Analytics System using Python, Pandas and MySQL

## Objective

The objective of this assignment was to design and develop an end-to-end E-Commerce Order Analytics System using Python, Pandas, and MySQL. The project covers the complete workflow from data generation and cleaning to SQL analytics and business reporting.

---

## Tools Used

- Python
- Pandas
- Faker
- MySQL
- MySQL Workbench
- Matplotlib
- SQL

---

## Dataset

A realistic e-commerce dataset was generated using the Faker library consisting of four related tables:

- Customers
- Products
- Orders
- Order Items

The dataset includes intentional inconsistencies such as:

- Duplicate records
- Missing values
- Invalid customer/product IDs
- Invalid email addresses
- Incorrect date formats
- Invalid quantities

---

## Tasks Performed

- Generated realistic datasets using Python and Faker.
- Introduced intentional data inconsistencies.
- Cleaned datasets using Pandas.
- Removed duplicates and handled missing values.
- Fixed invalid email addresses and date formats.
- Validated referential integrity between tables.
- Loaded cleaned data into MySQL.
- Performed SQL analysis using:
  - Joins
  - Aggregations
  - Window Functions
  - Common Table Expressions (CTEs)
  - Cohort Analysis
- Calculated business metrics such as:
  - Revenue by customer, category, and month
  - Top-selling products
  - Customer Lifetime Value (CLV)
  - Average Order Value (AOV)
  - Customer Retention
- Performed Customer Segmentation using RFM Analysis.
- Built a Command Line Interface (CLI) to generate reports.
- Implemented edge-case handling for invalid data and database errors.
- Generated business reports, charts, and CSV outputs.

---

## Output

The project generates:

- Raw datasets
- Cleaned datasets
- Issue report
- SQL analysis results
- Revenue reports
- Customer segmentation reports
- Cohort & retention analysis
- CSV report files
- PNG visualizations
